# NMI extension v1: interpretation matrix frozen before results

This matrix constrains claims after unlock. Results may change the narrative; they may not change
these evidential boundaries.

| Observed result | Permitted interpretation | Prohibited interpretation |
|---|---|---|
| DeepSeek matched self-proposal remains near zero | The proposal bottleneck persists for a much stronger model under this formal interface. | All modern LLMs categorically cannot change representations. |
| DeepSeek improves modestly but stays far below deterministic C3 | Stronger-model substitution narrows but does not eliminate the proposal/search gap. | The gap is a universal fixed property of model scale. |
| DeepSeek self-proposal succeeds substantially | The assay detects capability differences across model/runtime generations; Phi-4 is not representative of all current models. | The historical Phi-4 result was invalid or may be overwritten. |
| DeepSeek reaches or approaches C3 | This model/runtime internalizes much of the capability supplied by external deterministic search in these worlds. | Unrestricted autonomous scientific discovery has been demonstrated. |
| DeepSeek matched differs from native | Performance is sensitive to the reasoning regime and larger token budget; native is an ecological ceiling, not compute-matched evidence. | Reasoning effort alone caused the change, because model compute and token ceiling change jointly. |
| One repair produces a large rise before representation construction and final JSR | Serialization/structural interface failure materially constrained the no-repair condition. | Repair proves better scientific reasoning, or repaired outcomes replace the original condition. |
| Repair raises executable-plan rate but not J1–J5 | Syntax was a real failure mode but not the principal useful representation-proposal bottleneck. | Malformed outputs and conceptual failures are interchangeable. |
| Repair raises J1/J2 but not J4/J5 | The model can construct structurally outside, observationally adequate candidates but not reliably prospectively useful ones. | Structural novelty alone is discovery. |
| Strict schema helps substantially | Output-contract reliability is causally important under the tested interface. | Schema decoding supplies semantic truth or hidden outcome information. |
| Strict schema changes little despite syntactic validity | Failure lies after serialization, in typed construction or prospective utility. | Structured output was irrelevant in all possible interfaces. |
| Phi budget sensitivity improves markedly | Historical C_self was sensitive to an unusually tight 700-token completion ceiling and claims must narrow accordingly. | The larger-budget condition is compute-matched or replaces frozen C_self. |
| Phi budget sensitivity changes little | The frozen C_self conclusion is robust to a 2,048-token cap under otherwise unchanged opportunity and interface. | Token budget never matters for Phi-4 or other tasks. |
| Phi 8-bit changes outcomes substantially | The historical result is sensitive to the joint precision/serving-engine perturbation. | Numerical precision alone caused the difference. |
| Phi 8-bit changes little | Results are robust to this particular same-revision engine-plus-precision sensitivity. | All higher-precision runtimes would be identical. |
| P1/P2 vary by model | The nonsemantic model-call/parser gate is runtime-sensitive even though deterministic code supplies the scientific representation and fit. | Supplied-representation model reasoning has been measured. |
| C3 remains 400/400 without rerun | Existing evidence shows deterministic typed search can solve the aligned frozen worlds; it is already the no-self-proposal reference. | A new LLM was necessary for C3 or C3 establishes open-world discovery. |
| No-jump false positives appear | Report exact cases and inspect which gates admitted them; the operational assay is not perfectly specific under that treatment. | Exclude them as anomalies or tune thresholds after seeing them. |
| A shard or runtime fails | Preserve the attempt, follow the frozen transport/whole-shard rule and label missing evidence. | Selectively rerun unattractive outputs or impute success/failure. |

Across every case, the strongest allowed general claim remains: the study supplies a prospective,
executable assay that distinguishes search within a frozen language from validated gain after leaving
it and supports component-level attribution. “Discovery,” “creativity,” “generalization,” “model
inability,” “preregistration” and “false discovery” require narrower claim-by-claim qualification in
the final audit.
