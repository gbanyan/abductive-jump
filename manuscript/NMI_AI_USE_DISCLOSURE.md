# Proposed AI-use disclosure

The original experiments used a frozen `microsoft/phi-4` model as a registered experimental component. A separately frozen completion-budget sensitivity retained that model revision and 4-bit runtime while changing only the completion cap from 700 to 2,048 tokens. The minimal targeted sensitivity extension additionally used the same Phi-4 revision at 8-bit precision and the locally served `deepseek-ai/DeepSeek-V4-Flash-Vision-Exp` checkpoint under matched, native-reasoning and supplied-representation conditions. One separately frozen grammar-constrained condition used the same DeepSeek checkpoint with independent reasoning and answer stages, explicit parser syntax and no semantic feedback. Prompts, revisions, runtimes, decoding settings, budgets and outputs are described in the Methods and archived artifacts. A post-hoc component audit established that the original C3 scientific fields and verdicts were deterministic and did not require model output; a second provenance audit established that DeepSeek supplied graph-edit topology while the scaffold supplied motif realization, fit, ranking and intervention. These limitations are reported in the main text.

OpenAI Codex was used after completion of the original confirmatory experiments to inspect artifacts, implement and orchestrate the separately commit-frozen targeted sensitivity extension, recompute inference-free audits, verify literature metadata and journal guidance, and assist drafting and consistency checks. It did not choose hypotheses using observed outcomes, generate or modify historical confirmatory source data, change frozen evaluation rules or determine authorship. Human authors verified the cited metadata and remain responsible for originality, accuracy, interpretation and integrity.

All authors must review and approve this disclosure before submission.
