# Data and code availability

## Data availability

The tracked repository contains synthetic-world definitions, derived confirmatory result and comparison tables, configuration and reproducibility manifests, ancestry records, replay artifacts, and source data used for the reported analyses and figures. The original Phi-4 confirmatory state is preserved by commit, tag and archive branch. The minimal targeted sensitivity protocol, fixed seed panel, model configurations, completion validations, replay reports, analysis tables and figure source data occupy the separate `experiments/nmi_minimal_sensitivity_v1` namespace. The separately frozen Phi-4 completion-budget sensitivity remains in `experiments/nmi_extension_v1/results/phi_budget`; the grammar-constrained DeepSeek condition occupies `experiments/nmi_fair_interface_v1`, including its contract audit, frozen protocol, operational exclusions and replay. The frozen, inference-free realizer-dependence protocol, counterfactual replay, validation and analysis occupy `experiments/nmi_realizer_audit_v1`. Historical AJ5/CJ5 raw call ledgers and the raw superseded-extension shards are hash-addressed local research artifacts but are not tracked in the current Git repository. They must be included in the anonymized reviewer deposit and DOI archive before submission. Historical files are not overwritten or reclassified as extension results. No human, personal, clinical or restricted third-party data were used.

The repository includes `scripts/build_nmi_reviewer_archive.py`, which assembles a clean publication commit together with the ten historical confirmatory call ledgers, six completed superseded shards and three partial-run records. It writes an internal file-level SHA-256 manifest, excludes model weights and can stream-verify every member without extraction. The resulting local package is upload-ready but does not itself constitute a public deposit.

**Remaining pre-submission action:** build and verify the package from the final tagged publication commit; upload that exact package to an anonymized reviewer-accessible deposit and a DOI-minting repository such as Zenodo; and insert the DOI, accession and archive-level SHA-256 here. A branch URL or an unuploaded local package is insufficient for the final version.

## Code availability

The repository contains the source code for procedural generation, typed representation search, exact incumbent oracles, prospective intervention selection, J0–J5 evaluation, offline historical attrition reconstruction, targeted sensitivity analysis, grammar-constrained serialization, realizer counterfactuals, statistical analysis, figure generation, deterministic replay and reviewer-archive construction and verification. The archival release should identify the original confirmatory preservation tag, the Phi-4 budget and minimal-sensitivity protocol tags, the grammar-constrained-interface and realizer-audit protocol tags, the publication Git commit and DOI. Frozen `microsoft/phi-4` and `deepseek-ai/DeepSeek-V4-Flash-Vision-Exp` weights are referenced by exact repository identity and revision and are not redistributed; runtime versions, endpoint model metadata and decoding configurations are retained in manifests.

## Reviewer access

At submission, provide editors and referees with access to the complete repository or an anonymized immutable snapshot, including large artifacts if the public archival DOI is not yet active. Verify every path from the evidence-source map in a clean checkout.
