# Data and code availability

## Data availability

The tracked repository contains synthetic-world definitions, derived confirmatory result and comparison tables, configuration and reproducibility manifests, ancestry records, replay artifacts, and source data used for the reported analyses and figures. The original Phi-4 confirmatory state is preserved by commit, tag and archive branch. The minimal targeted sensitivity protocol, fixed seed panel, model configurations, completion validations, replay reports, analysis tables and figure source data occupy the separate `experiments/nmi_minimal_sensitivity_v1` namespace. The separately frozen Phi-4 completion-budget sensitivity remains in `experiments/nmi_extension_v1/results/phi_budget`; the grammar-constrained DeepSeek condition occupies `experiments/nmi_fair_interface_v1`, including its contract audit, frozen protocol, operational exclusions and replay. The frozen, inference-free realizer-dependence protocol, counterfactual replay, validation and analysis occupy `experiments/nmi_realizer_audit_v1`. Historical AJ5/CJ5 raw call ledgers and the raw superseded-extension shards are hash-addressed local research artifacts but are not tracked directly in Git. They are included in the manifested reviewer and preservation archives attached to the tagged submission release. Historical files are not overwritten or reclassified as extension results. No human, personal, clinical or restricted third-party data were used.

The repository includes `scripts/build_nmi_reviewer_archive.py`, which assembles a clean publication commit together with the ten historical confirmatory call ledgers, six completed superseded shards and three partial-run records. It writes an internal file-level SHA-256 manifest, excludes model weights and can stream-verify every member without extraction. It emits a byte-preserving package for DOI deposition and a separately manifested anonymous-review copy that redacts local account paths, repository email addresses and private LAN endpoints in a fixed audited file set without modifying source artifacts. These local packages are upload-ready but do not themselves constitute a public deposit.

**Submission release:** the public repository is available at https://github.com/gbanyan/abductive-jump. Both verified packages and their archive-level SHA-256 values are attached to the immutable `nmi-github-submission-v4` release at https://github.com/gbanyan/abductive-jump/releases/tag/nmi-github-submission-v4. A DOI-minted preservation copy will be deposited and cited before publication; it is not treated as a prerequisite for initial submission.

## Code availability

The repository contains the source code for procedural generation, typed representation search, exact incumbent oracles, prospective intervention selection, J0–J5 evaluation, offline historical attrition reconstruction, targeted sensitivity analysis, grammar-constrained serialization, realizer counterfactuals, statistical analysis, figure generation, deterministic replay and reviewer-archive construction and verification. Original software is licensed under Apache-2.0; original synthetic research data and derived artifacts are licensed under CC BY 4.0; manuscript materials, third-party content and raw model outputs are excluded as specified in `LICENSE_SCOPE.md`. The archival release identifies the original confirmatory preservation tag, the Phi-4 budget and minimal-sensitivity protocol tags, the grammar-constrained-interface and realizer-audit protocol tags, and the publication Git commit. Frozen `microsoft/phi-4` and `deepseek-ai/DeepSeek-V4-Flash-Vision-Exp` weights are referenced by exact repository identity and revision and are not redistributed; runtime versions, endpoint model metadata and decoding configurations are retained in manifests.

At submission, provide editors and referees with access to the complete repository or an anonymized immutable snapshot, including large artifacts if the public archival DOI is not yet active. Verify every path from the evidence-source map in a clean checkout.
